# HashHustle Android (Capacitor)

Capacitor wraps the HashHustle web app for the Google Play Store. It is fully
**additive** — the web app on port 3000 (SSR + backend) is untouched.

## What's here

- `capacitor.config.ts` — app config (id `com.hashhustle.app`, name `HashHustle`, `webDir: dist/client`)
- `android/` — the native Android project (Gradle), generated by `cap add android`
- `scripts/gen-cap-html.mjs` — generates `dist/client/index.html` from the built
  assets (TanStack Start's SSR build doesn't emit an `index.html`, but Capacitor
  needs one). The shell mirrors the SSR document; the client hydrates the whole
  document, so no `#root` div is required.
- `scripts/gen-android-icons.mjs` — generates HashHustle launcher icons from
  `src/logo.png` (legacy + adaptive foregrounds, all densities).

## Commands

```bash
npm run build:mobile       # vite build + generate dist/client/index.html
npx cap sync android       # copy web assets + plugins into android/
npm run cap:sync           # both of the above (rebuild + sync)
npx cap open android       # open in Android Studio
```

First-time platform creation is already done; to recreate it run
`npx cap add android` (needs `dist/client/index.html` to exist first).

## Android basics already configured

- Package / applicationId / namespace: `com.hashhustle.app` (see
  `android/app/build.gradle`)
- App label: `HashHustle` (`android/app/src/main/res/values/strings.xml`)
- `INTERNET` permission present in `AndroidManifest.xml` (required once the
  shell talks to the backend)
- Branded launcher icons (all mipmap densities + adaptive icons, dark `#0B0B0F`
  background) generated from `src/logo.png`
- Sync artifacts (`app/src/main/assets/public`, generated configs) are
  git-ignored by `android/.gitignore`

## Loading the app in the WebView

1. **Bundled (default):** `cap sync` copies `dist/client/` into the APK. The
   static shell renders the UI offline; mining/balance server functions need a
   reachable backend.
2. **Remote (recommended for real IAP):** uncomment `server.url` in
   `capacitor.config.ts` and point it at the deployed HashHustle origin. The
   WebView then loads the full SSR app, and Play Billing purchases can be
   verified server-side.

## Building an APK / AAB

Requires a machine with the Android SDK + JDK 17+ (not available in the dev
sandbox):

```bash
cd android && ./gradlew assembleDebug          # debug APK
cd android && ./gradlew bundleRelease          # signed AAB for Play Store
```
